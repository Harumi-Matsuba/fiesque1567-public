# 独立の2回目の書き起こし（Codex、2026-10-20）

**これは AI どうしの比較で、人による確認の代わりにはならない。人は書き起こしを確かめていない。**

## 方法
- 道具：OpenAI の Codex CLI（ChatGPT アプリ同梱の codex-cli 0.163.0-alpha.10.2、既定のモデル。実行記録にモデル名は出ない）。
- 書簡ごとに新しい文脈で1回ずつ、空のフォルダ second/empty2 から走らせた（second/run2.sh、`codex exec --ephemeral --skip-git-repo-check -s read-only --json`）。実行記録（*.jsonl）は6本とも返答1件だけで、コマンドの実行やファイルの読み込みはない。
- 渡したもの：行画像（このリポジトリには含めない。f.39r 28行・f.39v 19行・f.100r 27行・f.158r 23行・f.79r 24行・f.94r 25行）と、記号名の一覧（PROMPT2.md）。一覧は形の説明だけで、値・鍵・私の書き起こし・解読文は入れていない。
- PROMPT2.md は、前の照合（second/RESULT.md）で説明が紛らわしかった所を、形の説明として書き直したもの：十字形4種、ϖ と σ̄、輪のある y 形を一つの名前 y にまとめた、ꝭs・ß・16・∞ に尾などを足した。
- 1回目の書き起こしは、この実行の前にすべての修正を終えていた（画像で確かめられた修正だけを残した。second/run0/RESULT.md の「Codex の多数に合わせた50か所の見直し」）。この実行の結果を見て1回目を直したことはない。だから、この比較を「独立の2回目」とする。
- 比べ方：src/ind_compare.py。私の書き起こし（無効字を除く）と、行ごとに記号の並びを編集距離で対応させた。
  - 名前の一致：同じ名前。私の初めの名前 tt は、同じ ŧŧ／# 形なので H# と同じとした。
  - 値の一致：鍵で同じ字になるもの。輪のある y 形は形で見分けられないので、私の v（s）と 3p（p）を一つの組（値 s/p）とした。この組を除いた厳しめの値も並べる。

## 食い違いについて分かっていること（直していない）
- f.39r と f.79r では、私が // と書いた細く薄い斜め2画（Tomokiyo の表で a）を、Codex が区切りの線とみて書かなかった（50と37か所）。画像では、これらは記号と同じ高さの2画で、a と読むと「J'ay entendu」「et augmenter」「amys」などが通る（f.39r の7か所を拡大して確かめた）。PROMPT2 の「細い線は区切りなので書かない」という指示と紛らわしかったとみる。
- f.39r の C（ꝛ に薄い大きな輪）を、Codex は小文字の c と呼んだ（31か所）。拡大すると、どれも ꝛ 形に輪が付く C だった（6か所を確かめた）。
- f.39v の輪のある y 形を、Codex は C と呼んだ（10か所）。拡大すると、どれも y 形だった（6か所を確かめた）。
- f.39v で私が t 形（fx）としたのを、Codex は + と呼んだ（11か所）。どれも前の照合（second/run0/RESULT.md「t 形と + の確かめ」）で拡大して t 形と判断した箇所。
- ここに書いた確かめは、私の読みが正しいことを人が確かめたものではない。食い違いの残り（compare_run1.tsv）は、1つずつは見ていない。
