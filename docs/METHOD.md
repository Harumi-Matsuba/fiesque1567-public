# 方法・数字・AI の使用・限界

[English](METHOD.en.md)

## 1. 資料と画像
- BnF Français 15919（旧 Harlay 238 (8)）。174葉。Scipion de Fiesque（Scipione Fiesco）が皇帝マクシミリアン2世の宮廷（ウィーン）から、国王シャルル9世と王妃カトリーヌ・ド・メディシスに送った書簡（1567年10月〜1569年11月）。目録：https://archivesetmanuscrits.bnf.fr/ark:/12148/cc46124x
- 画像：Gallica ark:/12148/btv1b90573568（マイクロフィルム MF 15717 からのデジタル化、183コマの見開き）。BnF の IIIF の窓口（openapi.bnf.fr）から、原寸（幅約7000ピクセル）の画像を取得した（5秒間隔）。画像はこのリポジトリに含めていない。
- 対象は、友清理士氏が暗号の書簡として挙げた5通（f.39・f.79・f.94・f.100・f.158）。巻全体の暗号のページは約40ページで、残りは読んでいない。

## 2. 鍵
- 友清理士氏の復元表（Cryptiana「French Ciphers for German (and Eastern) Affairs」、https://cryptiana.web.fc2.com/code/frencheastern.htm 、2026-03-15 版）。同氏は「The reconstructed key below will allow reading undeciphered portions」と書いている。表の画像はこのリポジトリに含めていない。
- data/key.tsv：表の記号に名前を付け、値を書いた（出典 table）。表にない記号と無効字は、この書簡群の文脈から推定した（出典 inferred）。推定の一覧と根拠は key.tsv の4列目と [OPEN.md](OPEN.md)。

## 3. 書き起こし（1回目）
- Claude（Claude Code、Claude Opus 5.5）が、行ごとに切り出した画像（src/trackline.py ほか）を見て、記号を名前で書き起こした（data/transcription_*.txt）。区切りの細い縦線は書いていない。平文の語は、無効字の名前（.par など）で書くか、書き起こしから外した（各ファイルの注記）。
- 似た記号（十字形の4種、y 形など）は、形だけで名前を付けることを目指した。ただし、輪のある y 形の s と p は形で分けられず、文脈で読み分けている（[OPEN.md](OPEN.md) §1）。
- 機械的な解読：src/decode.py（data/decoded_*.txt）。

## 4. 照合と修正の記録（second/run0/）
- 先に、f.39r・f.39v・f.100r の行画像74枚を Codex に3回、1回目を見せずに書き起こさせ、私の書き起こしと比べた（second/run0/RESULT.md）。このときの記号名の一覧（PROMPT.md）には、説明が紛らわしい所があった。
- 食い違いを見て、私の書き起こしを直した。最終的に残したのは、画像を拡大して確かめられた修正だけ：
  - Codex の多数に合わせた50か所：47か所を確かめて残し、3か所は確かめられないので戻した（second/run0/RESULT.md 追記4の表）。
  - Codex が + と読んだ25か所：⊢ に8、+ に3を直し、12か所は t 形のまま。1か所は文脈で 4 にしたが、後で戻した。1か所は確かめられなかった（追記2）。
  - 「qu」の位置18か所：⊢ に14を直し、4か所は t 形のまま（追記3）。
  - f.100 の W と書いた4か所は、画像で ϖ と確かめて直した。
- この比較は、1回目を直すのに使ったので「独立」とは呼ばない。

## 5. 独立の2回目（second/ind/）
- すべての修正を終えた後に、6ページ（146行）の行画像を、書簡ごとに新しい文脈で Codex に1回ずつ書き起こさせた。Codex は OpenAI の Codex CLI（ChatGPT アプリ同梱の codex-cli 0.163.0-alpha.10.2、既定のモデル。実行記録にモデル名は出ない）。`codex exec --ephemeral --skip-git-repo-check -s read-only --json` を空のフォルダから走らせ、行画像と記号名の一覧（second/ind/PROMPT2.md、形の説明だけ）を渡した。値・鍵・1回目の読みは渡していない。実行記録には返答1件だけがあり、コマンドの実行やファイルの読み込みはない（tests/test_second.py で確かめる）。
- この結果を見て1回目を直したことはない。
- 比べ方（src/ind_compare.py）：行ごとに記号の並びを編集距離で対応させ、名前の一致と値の一致（鍵で同じ字になるもの）を数えた。私の初めの名前 tt は、同じ ŧŧ／# 形なので H# と同じとした。輪のある y 形は、私の v（s）と 3p（p）を一つの組（値 s/p）とした。この組を除いた値も並べる。

| 書簡 | 私の記号 | 名前の一致 | 値の一致 | y 形を除く値の一致 |

| f.39r | 1,169 | 75.2% | 76.1% | 75.3% |
| f.39v | 717 | 78.8% | 82.4% | 83.1% |
| f.79r | 793 | 76.5% | 81.5% | 81.8% |

- f.39r と f.79r の不足は、主に、私が // と書いた細く薄い斜め2画（表で a）を、Codex が区切りの線とみて書かなかったこと（50か所と37か所）。7か所を拡大すると、どれも記号の高さの2画で、a と読むと文が通った。プロンプトを直して走らせ直すと「良い回を選ぶ」ことになるので、していない。

## 6. 対照
- 鍵の文字の値（1文字の記号）をかき混ぜた鍵を1000個作り、本物の鍵と仏語らしさを比べた（src/control.py。wordfreq の仏語上位5万語で作った文字3連の対数尤度の平均。無効字は読み飛ばす）。表の記号だけを使う条件でも比べた。どの書簡でも、本物以上になった回は0回（数字は [READING.md](READING.md)）。
- 陽性対照（src/posctl.py）：La Ferrière 編『Lettres de Catherine de Médicis』t.3 にある Catherine から Fiesque への書簡（fr.15919 f.118 のミニュート）の本文を、この鍵で暗号化し、記号の取り違えを混ぜた疑似書き起こしを作った。約200記号・取り違え10%でも、本物の鍵は 0/1000 で見分けられた。乱数の記号列では 619/1000 で、見分けない。

## 7. 較正
- 較正はない。この巻に当時の解読（行間の書き込みや別紙）は見当たらず（全183コマを縮小で見た範囲）、La Ferrière 編の刊本にあるのは Catherine の返信だけで、Fiesque の暗号部分の平文は載っていないため。

## 8. 段階（このリポジトリの公開基準）
| 段階 | 条件 |
|---|---|
| B 部分的な読み | 対照で本物以上が0回、意味の通る一節が1つ以上、独立の2回目との一致 70% 以上（較正があれば文字 65% 以上） |
| C 全文の読み | B に加えて、独立の2回目 85% 以上、値の付いた割合 95% 以上（較正があれば記号 90% 以上か文字 85% 以上） |

- f.94r・f.100r・f.158r は C の条件を満たす。f.39r・f.39v・f.79r は B（独立の2回目が 85% に届かない）。
- 一致率は値の一致で判定した。名前の一致も並べている。

## 9. AI の使用
- 書き起こし（1回目）・表にない値の推定・解読・スクリプト・文書：Anthropic の Claude（Claude Code、Claude Opus 5.5）。
- 2回目の書き起こし：OpenAI の Codex（上記）。
- 人が行ったこと：対象の選定、画像の取得の許可、公開の判断。**人は書き起こしを確かめていない。** AI どうしの一致は、人による確認の代わりにはならない。

## 10. 限界
- 解読文の大半は【推】の行で、語の切れ目・綴りの補い・y 形の s／p の読み分けを含む。
- 史実との照合をしていない。
- 値の分からない記号（ρ・K・⊸・ꝺʒ・ꝑꝑ）と、推定の値（16＝ce、ꝭs＝t など）がある（[OPEN.md](OPEN.md)）。
