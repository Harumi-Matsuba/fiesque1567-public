# 方法・数字・AI の使用・限界

[English](METHOD.en.md)

## 1. 資料と画像
- BnF Français 15919（旧 Harlay 238 (8)）。174葉。Scipion de Fiesque（Scipione Fiesco）が皇帝マクシミリアン2世の宮廷（ウィーン）から、国王シャルル9世と王妃カトリーヌ・ド・メディシスに送った書簡（1567年10月〜1569年11月）。目録：https://archivesetmanuscrits.bnf.fr/ark:/12148/cc46124x
- 画像：Gallica ark:/12148/btv1b90573568（マイクロフィルム MF 15717 からのデジタル化、183コマの見開き）。BnF の IIIF の窓口（openapi.bnf.fr）から、原寸（幅約7000ピクセル）の画像を取得した（5秒間隔）。画像はこのリポジトリに含めていない。
- 対象：初版は友清理士氏が暗号の書簡として挙げた5通（f.39・f.79・f.94・f.100・f.158）。この版で、巻の中の暗号のページ全部（洗い出した44ページ）に広げた（§11）。

## 2. 鍵
- 友清理士氏の復元表（Cryptiana「French Ciphers for German (and Eastern) Affairs」、https://cryptiana.web.fc2.com/code/frencheastern.htm 、2026-03-15 版）。同氏は「The reconstructed key below will allow reading undeciphered portions」と書いている。表の画像はこのリポジトリに含めていない。
- data/key.tsv：表の記号に名前を付け、値を書いた（出典 table）。表にない記号と無効字は、この書簡群の文脈から推定した（出典 inferred）。推定の一覧と根拠は key.tsv の4列目と [OPEN.md](OPEN.md)。

## 3. 書き起こし（1回目）
- Claude（Claude Code、Claude Opus 5.5）が、行ごとに切り出した画像（src/trackline.py ほか）を見て、記号を名前で書き起こした（data/transcription_*.txt）。区切りの細い縦線は書いていない。平文の語は、無効字の名前（.par など）で書くか、書き起こしから外した（各ファイルの注記）。
- 似た記号（十字形の4種、y 形など）は、形だけで名前を付けることを目指した。ただし、輪のある y 形の s と p は形で分けられず、文脈で読み分けている（[OPEN.md](OPEN.md) §1）。
- 機械的な解読：src/decode.py（data/decoded_*.txt）。

## 4. 照合と修正の記録（second/run0/）
- 先に、f.39r・f.39v・f.100r の行画像74枚を Codex に3回、1回目を見せずに書き起こさせ、私の書き起こしと比べた（second/run0/RESULT.md）。このときの記号名の一覧（PROMPT.md）には、説明が紛らわしい所があった。
- 食い違いを見て、私の書き起こしを直した。最終的に残したのは、画像を拡大して確かめられた修正だけ：
  - Codex の多数に合わせた50か所：47か所を確かめて残し、3か所は確かめられないので戻した（second/run0/RESULT.md「Codex の多数に合わせた50か所の見直し」の表）。
  - Codex が + と読んだ25か所：⊢ に8、+ に3を直し、12か所は t 形のまま。1か所は文脈で 4 にしたが、後で戻した。1か所は確かめられなかった（同「t 形と + の確かめ」）。
  - 「qu」の位置18か所：⊢ に14を直し、4か所は t 形のまま（同「⊢ と y 形の確かめ」）。
  - f.100 の W と書いた4か所は、画像で ϖ と確かめて直した。
- この比較は、1回目を直すのに使ったので「独立」とは呼ばない。

## 5. 独立の2回目（second/ind/、初版）
- すべての修正を終えた後に、6ページ（146行）の行画像を、書簡ごとに新しい文脈で Codex に1回ずつ書き起こさせた。Codex は OpenAI の Codex CLI（ChatGPT アプリ同梱の codex-cli 0.163.0-alpha.10.2、既定のモデル。実行記録にモデル名は出ない）。`codex exec --ephemeral --skip-git-repo-check -s read-only --json` を空のフォルダから走らせ、行画像と記号名の一覧（second/ind/PROMPT2.md、形の説明だけ）を渡した。値・鍵・1回目の読みは渡していない。実行記録には返答1件だけがあり、コマンドの実行やファイルの読み込みはない（tests/test_second.py で確かめる）。
- この結果を見て1回目を直したことはない。
- 比べ方（src/ind_compare.py）：行ごとに記号の並びを編集距離で対応させ、名前の一致と値の一致（鍵で同じ字になるもの）を数えた。私の初めの名前 tt は、同じ ŧŧ／# 形なので H# と同じとした。輪のある y 形は、私の v（s）と 3p（p）を一つの組（値 s/p）とした。この組を除いた値も並べる。

| 書簡 | 私の記号 | 名前の一致 | 値の一致 | y 形を除く値の一致 |
|---|---|---|---|---|
| f.39r | 1,169 | 75.2% | 76.1% | 75.3% |
| f.39v | 717 | 78.8% | 82.4% | 83.1% |
| f.79r | 793 | 76.5% | 81.5% | 81.8% |
| f.94r | 855 | 91.5% | 91.9% | 91.6% |
| f.100r | 977 | 85.6% | 87.5% | 87.7% |
| f.158r | 832 | 85.3% | 90.5% | 90.1% |

- f.39r と f.79r の不足は、主に、私が // と書いた細く薄い斜め2画（表で a）を、Codex が区切りの線とみて書かなかったこと（50か所と37か所）。7か所を拡大すると、どれも記号の高さの2画で、a と読むと文が通った。プロンプトを直して走らせ直すと「良い回を選ぶ」ことになるので、していない。

## 6. 対照
- 鍵の文字の値（1文字の記号）をかき混ぜた鍵を1000個作り、本物の鍵と仏語らしさを比べた（src/control.py。wordfreq の仏語上位5万語で作った文字3連の対数尤度の平均。無効字は読み飛ばす）。表の記号だけを使う条件でも比べた。どの書簡でも、本物以上になった回は0回（数字は [READING.md](READING.md)）。
- 陽性対照（src/posctl.py）：La Ferrière 編『Lettres de Catherine de Médicis』t.3 にある Catherine から Fiesque への書簡（fr.15919 f.118 のミニュート）の本文を、この鍵で暗号化し、記号の取り違えを混ぜた疑似書き起こしを作った。約200記号・取り違え10%でも、本物の鍵は 0/1000 で見分けられた。乱数の記号列では 619/1000 で、見分けない。

## 7. 較正
- 較正はない。初版では「この巻に当時の解読は見当たらない」と書いたが誤りで、コマ23右にコマ22右の暗号書簡の当時の解読（平文の写し）がある。草書の平文を AI で確かに読めず、較正には使えていない（[OPEN.md](OPEN.md) §7）。La Ferrière 編の刊本にあるのは Catherine の返信だけで、Fiesque の暗号部分の平文は載っていない。

## 8. 全文の読み／部分的な読みの基準
| 状態 | 条件 |
|---|---|
| 部分的な読み | 対照で本物以上が0回、意味の通る一節が1つ以上、独立の2回目との一致 70% 以上（較正があれば文字 65% 以上） |
| 全文の読み | 部分的な読みの条件に加えて、独立の2回目 85% 以上、値の付いた割合 95% 以上（較正があれば記号 90% 以上か文字 85% 以上） |

- 初版では、f.94r・f.100r・f.158r が全文の読み、f.39r・f.39v・f.79r が部分的な読みだった。この版の判定は §14 と [PAGES.md](PAGES.md)（全44ページが全文の読み）。
- 一致率は値の一致で判定した。名前の一致も並べている。

## 9. AI の使用
- 書き起こし（1回目）・表にない値の推定・解読・スクリプト・文書：Anthropic の Claude（Claude Code、Claude Opus 5.5）。
- 2回目の書き起こしと画像の確かめ：OpenAI の Codex（上記）と Anthropic の Claude Sonnet（§12・§13）。
- 人が行ったこと：対象の選定、画像の取得の許可、公開の判断。**人は書き起こしを確かめていない。** AI どうしの一致は、人による確認の代わりにはならない。

## 10. 限界
- 解読文の大半は【推】の行で、語の切れ目・綴りの補い・y 形の s／p の読み分けを含む。
- 史実との照合をしていない。
- 値の分からない記号（ρ・K・⊸・ꝺʒ・ꝑꝑ）と、推定の値（16＝ce、ꝭs＝t など）がある（[OPEN.md](OPEN.md)）。

## 11. 巻全体への広げ方（この版）
- 全183コマを縮小で見て、暗号のあるページを洗い出し、全部を書き起こした（見落としがありうる）。コマ26・94 は平文だけ、コマ163右は f.158 だった。行の切り出しは src/autopage.py（行の中心を墨の量の山から求め、src/trackline.py で行をたどる）。
- 後半の手（コマ125以降）では、三角 ▲ は Δ（tri＝i）で丸い a（e）と別の記号、ℌ に似た尾つきの形は n（3n）、3 に似た尾つきの形は y（3y）。初めは三角を a と書いていたので、7ページを画像で見直して書き直した（各ファイルの注記）。
- 比べ方：行の対応を決めず、ページの記号を全部つないで編集距離で並べる（src/ind_compare4.py）。行単位の比べ方と、21ページで差は 0〜1.0 ポイント。

## 12. 食い違いの画像の確かめ
- 独立の2回目の2回（Codex の2回、または Codex と Sonnet）が、そろって1回目と同じように食い違った箇所を問いにした（src/mkcheck.py）。行画像の字の塊から位置を推定し、三角の印を付けて2.5倍に拡大した切り出しと、2つの読み（A・B、順は無作為）を、別々の読み手に見せた。読み手は Codex（新しい文脈）と Claude Sonnet（新しい文脈、1体あたり数十枚）、のちに Sonnet 2人。
- 直すのは、読み手がそろって2回目の読みを選んだ箇所だけ。y 形（s/p）の名前と、鍵にない名前は変えない（src/apply_checkp.py。決定の一覧は second/check/decisions*.tsv）。
- 取り直し：初めの Sonnet の確かめの一部で、画像の読み込みが空になったまま答えた回があった（Sonnet 自身の報告）。その答えは使わず（second/check/sonnet1_old/）、読み込みが空なら読み直す手順で全部を取り直した。前に直した箇所のうち、取り直した答えが支えない箇所は、元の読みに戻した。
- 確かめで「記号はない」とされて消した箇所の一部は、切り出しを見直した：切り出しが問いの場所を写していないもの、はっきり // があるものなどは元に戻した（各書き起こしの注記）。
- 直した後に、直す材料に使っていない新しい独立の2回目を取り、判定にはその回だけを使う（[PAGES.md](PAGES.md)）。

## 13. Claude Sonnet による独立の2回目（参考）
- Sonnet に、PROMPT3 と行画像を渡して書き起こさせた。行画像（幅約3000ピクセル）をそのまま渡すと縮小されて小さな記号が見えず、f.39v で値の一致 63.4% だった。行を左右半分に分けて原寸で渡し、1行ごとに見た直後に書かせると 78.0%、3分割では 76.5%。同じページの Codex の2回は 89.4%・90.1%。
- 食い違いの型は、⊣ を t 形・＋・1 と読む、lr（b）を L と読む、Þ を三角と読む、7 形を名付けない、など。記号の説明に区別を書いてあっても起きたので、読み手の限界とみる。
- このため、Sonnet の回は参考に並べるだけで、判定には使わない。

## 14. 状態の判定
- 判定に使うのは、その書き起こしを直す材料に使っていない独立の2回目だけ。値の一致の低い方と、値の付いた割合、対照で、§8 の基準に当てはめる（[PAGES.md](PAGES.md)）。

## 15. コマ168右（v168r）のプロンプト
- このページでは、Codex の独立の2回目が回を重ねても 74.8〜83.0% で上下した。4回を行ごと・型ごとに見ると、三角→a（4回で計43）と Þ→三角（計21）が同じ向きにそろって多く、画像の確かめでは Sonnet 2人がどれも1回目の読み（三角・Þ）を選んでいた。読みを入れ替えると仏語らしさは下がる。この手の Þ は縦画の右上に黒く塗った楔が付いた形で、PROMPT3 の説明「右上に閉じた輪」と合わず、Codex は Þ を三角と、平たい黒い ▲ を a と呼んでいたと見る。行の切り出しは、行ごとの記号の数が近く、外れていない。
- そこで、答えの値を入れずに、a・三角・Þ の説明だけをこの字形に合わせたプロンプト（second/PROMPT3_v168r.md）で、新しい文脈の2回を取った（second/ind21・ind22）。値の一致は 88.5%・85.6%。三角→a は1回あたり16→2、Þ→三角は5→0 に減った。このページの判定はこの2回による（[PAGES.md](PAGES.md) の「Codex*」）。書き起こしは、この間に直していない。
