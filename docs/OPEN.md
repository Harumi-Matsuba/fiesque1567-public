## 2. 無効字
- 平文の字の組（fo・Ea・of・fv・Il・par・moy・bro・au・ri・ol・ti・fi・Dav・Day・La）を、無効字として書き起こしから外している。Tomokiyo の表の nulls 欄にあるのは、fo・Ea・of・fv・Il・par と「…」だけ。ほかはこの書簡群の文脈から推定した。
- 行の中の「receu」「Jay」なども平文として外した。暗号の一部である可能性は確かめていない。

## 3. 書き起こし
- 人は書き起こしを確かめていない。書き起こしは Claude が画像から行い、Codex による独立の2回目と比べた（second/run0/・second/ind/）。AI どうしの一致は、人による確認の代わりにはならない。
- 十字形（⊢＝q、t 形＝c、太い＋＝o、⊣＝r）の見分けは、拡大してもわずかな差で決めた箇所がある。⊣ か t 形か決められなかった3か所（f.39r c27 #25、f.39v c19 #16、f.100 c24 #22）と、+ か 4 か決められなかった1か所（f.100 c04 #8）は、初めの読み（t 形）のまま。
- f.94 の c08–c15 は、行画像の左右のつなぎ目で記号が重なって写っていた。重なりは目で除いた。
- f.100 c01 #4 と c21 #1・c25 #23 は、切り出しが外れて形を確かめていない。
